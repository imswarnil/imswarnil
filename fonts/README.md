# Vendored fonts

Committed so the SVG build is reproducible and offline — the render step turns text into
outlines, which needs the actual font files, not a webfont link.

| File | Family | Licence |
|---|---|---|
| `SpaceGrotesk-Medium.ttf`, `SpaceGrotesk-Bold.ttf` | [Space Grotesk](https://github.com/floriankarsten/space-grotesk) | SIL Open Font Licence 1.1 |
| `IBMPlexMono-Regular.ttf`, `IBMPlexMono-Medium.ttf` | [IBM Plex Mono](https://github.com/IBM/plex) | SIL Open Font Licence 1.1 |

Both are OFL 1.1, which permits redistribution alongside the licence. Neither is modified.
